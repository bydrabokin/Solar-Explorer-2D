# Solar-Explorer-2D

A 2D solar system explorer sandbox that works as an encyclopedia of the solar system giving information about planet's properties, atmospheres, orbits and much more. 

# Why this exists
It is a passion project and an introduction to a much larger 3D solar system that will include moons, spacecraft and many more features
